A structured collection of **Exploratory Data Analysis (EDA) lab assignments and practical work**, developed using Python.

This repository covers the complete data preprocessing and exploratory analysis workflow, including:

- Data cleaning
- Missing value handling
- Data imputation
- Discretization and binning
- Feature scaling and normalization
- Outlier detection
- Statistical analysis
- Data visualization
- Dimensionality reduction using PCA and t-SNE

The techniques are demonstrated using multiple real-world and standard datasets such as **COVID-19, Wine Quality, World Happiness, Suicide Statistics, Employee Records, Iris, and MNIST**.

## 🔍 Overview

This repository is a practical, hands-on implementation of core **Exploratory Data Analysis and Data Preprocessing concepts**.

Each experiment focuses on a particular stage of the data analysis pipeline. The scripts are designed to be:

- Easy to understand
- Self-contained
- Reusable
- Suitable for lab/practical work
- Extendable for future machine learning projects

The repository progresses from basic data cleaning and preprocessing to visualization and dimensionality reduction.
